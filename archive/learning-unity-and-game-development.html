Learning Unity and Game Development

13 jan 20252025 年 1 月 13 日 · 3 min read约 3 分钟读完

这篇文章写于在学校的课程期间，原文是英文。

Overview

During this period of learning Unity, I not only grasped the basic tools and technologies for game development but also gained a deeper understanding of how to create interactive experiences, optimize game effects, and debug programs through Unity. The following are the main gains I obtained during this learning:

Core Concepts of the Unity Engine

Through learning Unity, I got a comprehensive understanding of the structure and functions of the game development engine. As a powerful game engine, Unity is applicable to both 2D and 3D game development and also supports virtual reality (VR) and enhanced reality (AR). Its intuitive interface and powerful physics engine enable developers to quickly implement game logic and conduct efficient debugging. Initially, I was unfamiliar with Unity’s interface and various windows (such as Hierarchy, Scene, Inspector). However, as I delved deeper into the learning, I gradually understood how these windows work together to help me manage game objects, adjust object properties, and visualize scenes.

Game Objects and Component-based Design

In Unity, GameObject is the basic unit that constitutes the game world. One of the key concepts I learned is component-based design, which means splitting different functions (such as physics, sound, appearance) into independent components and achieving complex functions by attaching these components to game objects. This design approach made me understand how to control the behaviour of objects through scripts, physical components, collision bodies, and materials, rather than simply placing graphics or models. Each component can be adjusted independently, thus affecting the behaviour or interaction of game objects.

Application of the Physics Engine

Unity’s physics engine is an indispensable part of game development, especially when creating scenes involving object movement and collisions. During the learning process, I got in touch with basic physical components like Rigidbody and Collider and learned how to make objects follow physical rules, such as gravity, friction, and elasticity. I also used Physics Materials to adjust the friction and elasticity of objects and understood how the physics engine makes virtual objects interact as if they were in the real world. By applying these physical effects, I could create more realistic movement and collision effects, enhancing the immersion of the game.

Summary

Through this learning of Unity, I not only mastered the basic tools and technologies for game development but also deeply understood the core elements in game design, such as user experience, interactivity, and physical effects. I realized the creativity and technicality behind game development. In the future, I hope to further study more advanced features, such as AI path planning, lighting and shadow effects, Shader programming, etc., to improve my technical level and create richer and more innovative game experiences.
