TeleAgriCulture Web App Rebuild & Development – Pitch Document

14 feb 20262026 年 2 月 14 日

这篇文章写于在学校的课程期间，原文是英文。

Author: Qingzhou Cai (Coco)

Semester / Course: ARTD2143 Creative Industries

Date: 13/02/2026

Project Overview

TeleAgriCulture is an ongoing art, research, and technology platform exploring bio-digital ecologies, environmental sensing, and community-based climate knowledge through creative computing and participatory design.

This project focuses on rebuilding and extending the existing TeleAgriCulture Web App and Archive to improve usability, clarity, and community engagement. It is a production-focused, real-world development project, contributing to an active platform with live users and datasets.

Problem & Opportunity

Challenges

  • Environmental data is complex and difficult for non-expert users to interpret.
  • Web App navigation and interface are not always intuitive.
  • Limited community interaction features.

Opportunity

  • Improve usability and make environmental data more legible through visual and iconographic storytelling.
  • Enhance community collaboration and engagement.
  • Support active field pilots with rapid prototyping and user feedback.

Project Objective

The main objectives are to

  1. Audit, rebuild, and extend the existing web app.
  2. Improve usability and interface clarity.
  3. Make environmental data more legible using visual story modules.
  4. Add and enhance community interaction features such as notifications, forums, and user profiles.
  5. Provide a prototyping sandbox for pilots and iterative testing.

Feature Highlights

Visual Story Modules

The Visual Story Modules integrate sensor data, weather data, and historical information into intuitive, icon-based visual modules. By using colour, animation, and simple icons, these modules communicate environmental states in a way that is immediately understandable. For example, a temperature increase may be shown with a sun icon and a colour gradient, while stronger wind can be visualised with animated leaves or arrows. Each module represents a mini story, conveying environmental changes without relying on numbers or complex charts.

Community Module

The Community Module offers a small forum and comment section within the web app where users can share observations, photos, and reflections on environmental data. The platform encourages interaction by linking discussion topics to the data stories, for instance, a high humidity reading might prompt members to share experiences from the rainy season. This creates a collaborative space for learning and reflection, connecting users through shared environmental insights.

Prototyping Sandbox

The Prototyping Sandbox provides an experimental area for both students and community users. Here, different icon and visualisation combinations can be tested to see which designs are most intuitive. The sandbox allows for rapid iteration and user feedback, ensuring that upcoming field pilots can be informed by real usability insights. It serves as a hands-on space for creative experimentation and design optimisation.

Icon Library

The app includes a Minodu-style icon library, designed for easy integration into visual story modules. Users can drag and drop icons to customise their modules, and the library is expandable to accommodate different community contexts. The icons prioritise non-numerical readability and cultural adaptability, ensuring that the visual language of the app is accessible and engaging to a wide audience.

Innovation & Pitch Highlights

  • Non-numerical Data Stories: Icons, colour, and animation allow immediate understanding without relying on numbers.
  • Community-aware Visualizations: Data presentation encourages discussion and collaboration.
  • Rapid Iteration: Integrated with pilots, real-time feedback informs visualisation improvement.
  • Paid Continuation Potential: Modular design allows sustainable expansion beyond the semester.

Technical Aprroach

  • Front-end: HTML + CSS + JavaScript or WordPress
  • Back-end: SQL (using existing TeleAgriCulture data structures)
  • Data Visualisation: p5.js / Chart.js / Canvas
  • Icon & Story Modules:
    • Drag-and-drop SVG icon library
    • Real-time binding to sensor data
  • Prototyping Sandbox:
    • Independent sandbox page for testing
    • Pilot-ready for user comprehension and feedback

Expected Outcomes

  • Functional, production-ready TeleAgriCulture Web App.
  • Interactive, visual story modules for environmental data.
  • Enhanced community interaction features.
  • Rapid prototyping space for pilot testing and iterative improvements.
  • Clean, documented code for future development.

Impact & Next Steps

Impact

  • Supports real users and strengthens community engagement.
  • Makes environmental and agricultural knowledge accessible and actionable.
  • Empowers users through interactive, non-numerical data storytelling.

Next Steps & Timeline

  • Week 5: Complete core feature prototypes.
  • Week 6: Pilot testing and feedback collection.
  • End of Semester: Deliver integrated, production-ready Web App.

Pitch Summary

I aim to develop an interactive visual story module for the existing TeleAgriCulture Web App, using icons, animation, and non-numerical visualisation to make environmental data understandable for non-expert users, enhance community interaction, and provide a rapid prototyping sandbox for upcoming pilots.
